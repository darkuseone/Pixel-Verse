## Уроки YouTube Studio (08.11, 28 дней, 36 Shorts; `docs/stats-ru.md`, `docs/episode-formula.md` §11)
- **KPI v2:** «продолжили» ≥ 75 % (главный, связь с просмотрами 0,64), заинтересованные / просмотры ≥ 55 %, реальное время на просмотр ≥ 50 % длины. «Средний % просмотра» YouTube — только по не пролистнувшим, целью не служит. Разбор выгрузки: `python3 -I engine/ytstudio.py <3 csv>`.
- **Хит = сезонная телесная боль + число на предмете в кадре:** «+14 ДОМА?!» (44 тыс.), «40 БАНОК?!» (32 тыс.), «+32» (29 тыс.) = 51 % просмотров канала. Герой кричит «число + ?!» с 0,0 с. Физическое число 74 % «продолжили», денежное 58 %.
- **Тема по неделе выхода** (календарь §11.3): те же сюжеты вне пика — 1,4–2,3 тыс. S03 «Дача» не в ноябре.
- **Хук говорит главный герой** и фраза понятна без контекста (не «Посыпано?!», не поверщики через глазок).
- **Байт — число, не выбор, и не голосом в конце:** вопрос-цифра текстом поверх кнопки + описание + закреп. Голосовое «Записал… Пишите.» кота = обрыв кривой −12…−15 п.п. сразу после него (E01, E06); последняя реплика — только панчлайн, после неё ≤ 0,5 с (критик: ENDING).
- **Первая абсурдная картинка ≤ 8 с:** «Тёща» E03 — четыре реплики-объяснения до таза оливье на 11,9 с → к 20-й секунде 71 % против 80–83 % у Валеры (§11.8).
- **«Тёща» (понятная история):** пол высокий (63,9–75,4 %, ср. 87,5 %), потолка нет, 1 комментарий на 28,9 тыс. → хук из боли недели + вопрос-цифра в описании.
- **YouTube не копит аудиторию:** 93 % новых, 2,9 % вернувшихся → плейлист сезона, связанное видео, закреп, мини-кадр хука следующей серии в плашке поверх последнего удара (не отдельным битом); финал сезона = петля сезона.

## Формула серии (9:16, 30–32 с, коридор 30–38)
боль + абсурдная картинка с 0,0 с → крик-хук → панчлайн каждые 4–5 с → поворот на 50–60 % (≤ 18 с) → кнопка → петля.
- **Хук = три совпадения:**
  - первый кадр — лицо + крик + предмет конфликта, читается за 1 с без звука (обрыв кривой на 0:01);
  - текст-хук 2–4 слова, крик («СКОЛЬКО?!»);
  - первая реплика с 0,0 с.

  Обложка = текст-хук.
- **Поворот меняет смысл всего до него,** подготовлен уликой, подчёркнут звуком + вспышкой + стикером. Тип в сезоне не повторяется. Каталог типов: `episode-formula.md` §3.
- **Юмор:** тупой/физический в хуке, сарказм системы в середине, абсурд/чёрный на повороте, сухая кнопка в камеру. Каждая третья шутка визуальная. Реплика ≤ 12 слов, удар в конце.
- **Понятность важнее частоты склеек:** герой проговаривает, что случилось; одно действие — один план 3–6 с с движением камеры.
- **Байт внутри ролика** (22.10):
  - спорный выбор в кнопке («Кто прав — Валера или касса?») + стикер с двумя вариантами на последние 2 с — **с 08.11 заменено:** вопрос-число только текстом и в закрепе, голосом в конце не спрашивать (§11.8);
  - в каждой второй серии — «отправь тому, у кого…»;
  - плашка «ПОДПИШИСЬ — завтра …» обещает следующую серию;
  - у каждого героя коронная фраза в каждой серии.
- **Плашка курса** во всех новых РУ-сериях: `Episode(..., promo='ru')` (`engine/promo.py`), готовые — `promo.py apply`.
- **Плашка подписки** за 1 с до конца (16:9 — за 3 с): `Episode(..., endcard=dict(style, lang))`.
- **Кнопка и сразу конец,** хвост ≤ 0,3 с.

## Визуал
- Герои ×2 разрешения: пиксель героя ≤ 3,75 px на экране (`res_for`). Задник за крупным планом зум ≤ 1,45 или blur.
- Надписи только внутри табличек (`decals.plate`, `txt_box`), важная вывеска не режется краем кадра.
- 5–10 местных табличек и мелочей на локацию + анимированная мелочь. Кадр физически возможен: ноги на полу, тень. Видно, кто говорит: рот, волны, эквалайзер.

## Звук
- **Голоса:** eleven_v4, теги эмоций в каждой реплике. РУ — U+0301 в словах из 2+ слогов (в субтитрах их нет); US — КАПС ударения, без многоточий. STT не запускаю. `tighten.py`.
- **Перед генерацией** проверяю, что voice_id живы: скил `/voices`.
- **Свои звуки у каждого сериала** (`series/<slug>/sfx/`), никаких «миди»-плинков. `sfxcheck.py` перед миксом.
- **Музыка:** короткий луп ~15 с. Бесплатно — синтез кодом (`series/mazutych/music/gen_music.py`), иначе ElevenLabs `music_v2_5`. Скил `/music`.
- **Микс:** с 25.10.2026 (тест) −14 LUFS / −1 dBTP: `LUFS = -14.0` в `timeline.py`; старые серии mean −20…−22 dB. `engine/mix.py`.
