# Пайплайн PIXEL VERSE: технические находки и ловушки

> Актуальный порядок работы и правила — в `CLAUDE.md` (v5, 01.10.2026): длина серии 30–45 с, обложка вшита в первые 0,1 с, цели удержания > 80 % и «не пролистнули» > 75 %. Здесь только техника и ловушки; при расхождении главнее CLAUDE.md.

Читать в начале новой сессии вместе с CLAUDE.md. Основано на «Почти Диком Западе» (сезон 1, сентябрь 2026).

## 1. Серия-шортс (9:16) — рабочая схема
1. **Сценарий сначала**, короткий: хук в первые 2 с, поворот на 60–75 %, «кнопка», петля/тизер. Реплики ≤ 12 слов. Длина **30–38 с** (досмотр упирается в ~24 с). «Ок» пользователя до трат на озвучку, если он не сказал «делай сам».
2. **Озвучка** `eleven_v4`, ударения U+0301, теги эмоций, потом проверка через `scribe_v1` (скрипт `series/<slug>/movie/check_voice.py` — образец, с повторами при сетевых сбоях). Новая реплика стоит ~5–12 кредитов. Готовые реплики («Спасибо.», «Не-а.») переиспользуем из `voice/`.
3. **Задники** через xAI (`engine/xai.py`, 2–3 на серию, 16:9, без людей и без текста, ≈ $0.06), потом квантование 110 цветов (`stage.ai_world`). Надписи на вывесках дорисовываем кодом. Герои — `engine/props/chars.py`, свет `stage.Light`, тени `stage.shadow`, частицы `engine/fx.py`. Реквизит серий 1–2: `engine/props/pilot.py`.
4. **Камера**: короткие планы 1,5–3 с. Для скачек лучше «кроссинги»: в каждом плане герой заново въезжает с края, камера едет за ним (мир одной картинкой конечен). Скорость: `fx.speed_lines`, пыль, мошки. Крупные планы лица Z≈2,5–3.
5. **Обложка**: кадр-референс из кода → `/images/edits` xAI → пикселизация + табличка + крупный заголовок (`engine/covergen.py`, `episodes/epNN/cover.py`). Вшивается в первые 6 кадров (`Episode.encode`), поэтому **обложку делаем ДО финального рендера**. Английские надписи ИИ на плакатах (например «WANTED») **оставляем**: русской аудитории это знакомо (решение пользователя 30.09).
6. **Рендер** кусками в 4 процесса (`python epNN.py all 4`, ~1,5 мин на серию), `mix.py` для звука (среднее −20…−22 дБ, пик ≤ 0), проверка кадров листом до рендера и после.
7. **Тексты публикации**: у каждой сети своё название и описание (похожие, но разные), мульт + номер серии, 3 хэштега, метку «ИИ» не ставим, YouTube категория 1 «Фильмы и анимация».
8. **Buffer только для статистики.** Ничего не планировать и не публиковать, пока пользователь сам не скажет.

## 2. Ловушки, на которые уже наступали
- **Готовые серии не пересобирать** без прямой просьбы (E05 пришлось откатывать).
- Один процесс рендерит несколько блоков/глав: `stage.set_px(k)` меняет глобальный размер пикселя героев. Код со «своим» холстом (салун E03) должен вызвать `ST.set_px(1)` перед кадром, иначе герои обрежутся.
- PX героев в 16:9 не больше 2 (640/3 не целое).
- Большие файлы: серия шортс 15–30 МБ нормально; **лимит отправки в чат 30 МиБ**: если `final.mp4` > 29 МиБ, пересобрать `PV_CRF=23 python3 epNN.py all 4` (−20…25 % веса, пиксели не страдают; E05: 34,2 → 26,8 МиБ). Всё >100 МБ только через **Git LFS** (`apt-get install git-lfs`, `git lfs track`), ссылка `https://media.githubusercontent.com/media/<owner>/<repo>/<branch>/<path>`.
- Кэшированные ссылки в Buffer: при замене файла по той же ссылке добавлять `?v=…`, иначе остаётся старая длительность.
- Стоп-лист реплик (`«Можно. А зачем?»`) проверять при переиспользовании старых озвучек.
- Лимит ElevenLabs — по кредитам плана (145 565 в месяц, осталось ~15 000 на 30.09); музыка ~900 за трек, реплики копейки.

## 3. Длинная расширенная версия сезона (16:9) — только по отдельной просьбе, и КАЖДЫЙ РАЗ СВОЯ
Пользователь просит её после завершения сезона. Для сезона 1 «Почти Дикого Запада» она уже сделана: `series/pochti-dikiy-zapad/movie/` (`script.md`, `meta.md`, `final_master.mp4` в LFS, 7:15). Не начинать без просьбы.

**Главное правило: это НЕ шаблон.** Сценарий длинной версии придумывается заново под характер, юмор и сеттинг каждого мульта. Рамка «Молния-режиссёр, главы, счётчик дней, реклама Сэма, ляпы» — это решение именно для Дикого Запада; **не переносить её на другие мульты**. Для нового мульта сначала думаем: какая у него собственная форма выпуска (например, «выпуск новостей», «прямой эфир», «допрос свидетелей», «инструкция по эксплуатации», «сборник ошибок», «судебное заседание», «экскурсия по локациям» — что подходит герою и шутке), какой сквозной счётчик или ход, какой хук из финала сезона. Повторять схему можно только для **второго сезона того же мульта** (та же рамка развивается).

**Что общее для любой длинной версии (техника и требования, не сюжет):**
- Не склейка Shorts: новая драматургия, ≥ 50 % нового материала (иначе YouTube может счесть «повторяющимся контентом»): новые сцены, реплики, задники, звук.
- Хук в первые секунды, смена ситуации примерно каждые 30 с, паузы-«вставки» между главами, финал с крючком на следующий сезон, сцена/титры по желанию сюжета.
- Формат 16:9, 1920×1080, 30 fps. Движок: `PV_WIDE=1` (`engine/stage.py`, `overlays.py`, `widecam.py`); вертикально написанные кадры конвертируются автоматически (`widecam.View/view_at`), сплиты рядом (`halves`), оверлеи `movie/wideov.py`, перемотка `fx.vhs`.
- Структура проекта (как в `series/<slug>/movie/`): `script.md` (таймлайн), `blocks/*.py` (новые сцены: DUR/VOICE/SFX/BEDS/render), `chapters/ch_epNN/` (копии сцен готовых серий, оригиналы не трогаем), `movie.py` (`plan` / `sheet <блок>` / `video 4` / `audio` / `final`), `audio.py` (микс по блокам + loudnorm).
- Порядок: своя идея формы → сценарий → «ок» пользователя → озвучка новых реплик (+STT) → SFX и 1–2 музыкальных лупа → задники xAI (~8) → блоки + листы кадров → рендер (~25 мин на 7 минут) → микс → проверка кадров → обложка 16:9 → `meta.md` с главами (таймкоды) → LFS.
- Ориентир бюджета (сезон 1): ElevenLabs ≈ 1 000 кредитов, xAI ≈ $0.7.
- Выдача: `final_master.mp4` (CRF 20, ~250 МБ) через LFS + `cover.jpg` ≤ 2 МБ + `meta.md`. Публикует пользователь (Buffer не берёт LFS-ссылки и он только для статистики).
