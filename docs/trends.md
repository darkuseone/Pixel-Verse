# Тренды и мемы

Формат: мем → смысл → как вложить → дата → статус (свежий / стареет / мёртв).
Мем — специя: шутка обязана работать без знания мема.

Накопительная база (правило владельца, 30.09.2026): каждая разведка перед новым русским мультом дописывается новым разделом с датой, ничего не удаляем. Перед новым мультом читаю файл целиком и не повторяю уже использованные мемы и гэги. Американская база — отдельно, `docs/trends-us.md`.

Вывод для юмора: в тренде постирония и абсурд, поданный всерьёз, но самые массовые ролики — узнаваемый быт. Формула сезона: бытовая боль, понятная с первого кадра без звука, + армейская логика Валеры + сухие реплики кота в камеру.
