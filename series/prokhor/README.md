# «Прохор. Таёжные лайфхаки» (РУ)

Заказ владельца 12.10.2026: карикатурный мужик — лайфхакер из тайги, нелепые абсурдные истории, общая нить сезона, каждая серия — самостоятельная мини-история, 35–38 с; после сценария сразу пилот.

- Сценарий сезона: `season1_script.txt`. Статус: `STATUS.md`.
- Герои и манера «Морозный лубок»: `design/philosophy.md`, `design/cast_sheet.png`; код — `engine/props/taigapix.py` (манера), `taigacast.py` (каст и реквизит), `taigakit.py` (свет, миры, титр, рамка блога, FX), `taigadecor.py` (антураж-декали). Обложки — `engine/covergen_taiga.py`; плашка подписки — стиль `taiga` в `engine/endcard.py`.
- Голоса (`voices.json`, реестр `docs/voices.md`): Прохор (коралловые субтитры), Михал Потапыч (ледяные голубые).
- Задники xAI: `bg/izba.png`, `bg/taiga.png`, `bg/den.png` (`gen_bg.py`). Музыка: `music/prokhor_theme_15s.mp3` (балалайка, баян, ложки).

## Чем герои отличаются от всех существующих
Своя манера (плоский трёхтон с жёстким краем, без дизеринга/штриховки/растра), свой свет (низкое солнце слева + голубая подсветка снега снизу), еловая тушь, силуэты «сугроб с бородой» (пирамида) и «груша меха», палитра «холодный снег против рыжей бороды». Не похожи на Валеру, Мазутыча, ковбоев Запада, Agent Dibs, Florida Man, Grim.

## Сквозные гэги
«Лайфхак номер N!» в рамке блога (REC), «Городские, учитесь!» + осаживание, «Плюс пени.» (медведь; в E05 — Прохор), табличка долга (счётчик сезона), «ЛОВИТ ТУТ» на сосне, пузырь из носа медведя, «НЕ БУДИТЬ!».
