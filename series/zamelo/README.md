# «Замело» (РУ)

Дальний Восток, снег по девятый этаж. «Девятый теперь — первый». Жора с девятого этажа («Мы, дальневосточники, — привычные!») каждый день проигрывает снегу, соседу, УК и чайке («Я — чайка. Баклан — это ты.»).

- Сценарий сезона: `season1_script.txt` (одобрен владельцем 14.11.2026).
- Герои и манера: `design/philosophy.md`, `design/cast_sheet.png`; код — `engine/props/zampix.py`, `zamcast.py`, `zamkit.py`, `zamdecor.py`.
- Голоса (Voice Library, без слотов): `voices.json`.
- Задники xAI: `gen_bg.py` → `bg/` (+ карты глубины `*.depth.png`, стиль 2.5D).
- Свои звуки: `sfx/`; подложка — CC0 «Мандолина» (`library/cc0/music/komiku_mandolin.mp3`).
- Пародийные бренды: ОЗНОБ (маркетплейс), САНОКАТ (доставка), ЯМЩИК Go (такси на собаках), УК «СУГРОБ-СЕРВИС», КРАБ-МАРКЕТ.
- Обложка: табличка — сине-белый дорожный указатель «ЗАМЕЛО! • СЕРИЯ N/6» с сугробом и сосульками; заголовок — «аляска» (жёлтый → оранжевый, тёмно-синяя обводка, низ букв в сугробе). Плашка подписки `endcard style='zamelo'`.
