# S01E02 «ЗВОНЯТ ИЗ БАНКА?!» — 30,4 с

Хук (0,0–2,7): звонит кнопочный телефон, карточка «ВХОДЯЩИЙ ВЫЗОВ: СЛУЖБА БЕЗОПАСНОСТИ «СБЕРЁГ»» — «Служба безопасности банка «Сберёг». Ваша смерть — в опасности!»; текст-хук = обложка «ЗВОНЯТ ИЗ БАНКА?!».
Кощей косится на сервант (хрустальная утка): «Откуда вы знаете, где она?!» → «Я — Кощей Бессмертный! Меня не обманешь!» — «Тогда продиктуйте код из СМС.» — «Семь. Три.» (Кузьмич из-за серванта крутит пальцем у виска) → «Иглу положите на балкон.» — Кощей несёт яйцо с иглой.
ПОВОРОТ (55 %, 16,6 с) — злодей свой: отъезд на фасад, балконом выше Змей Горыныч с тремя телефонами и ноутбуком «КОЛЛ-ЦЕНТР 24/7», леска тянется к игле — «О, сосед! Здорово!» — «Горыныч?!» — «Это не мы. Это — алгоритм.»
Добивание: Яга с лавки: «Горыныч! Мне тоже звонили — внуком!» — третья голова: «Бабуль, это тоже я.» Кнопка: Кузьмич — «Жуть.» Петля: телефон звонит снова (= первый кадр).
Счётчик: календарь «ДО ХЭЛЛОУИНА: 5».
