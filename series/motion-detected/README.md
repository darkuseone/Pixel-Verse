# MOTION DETECTED (US) — сериал
Папа из пригорода Гленн Холлис против праздничного сезона; комментатор — его умный дверной звонок Дорис (KNOCKR Pro), продавец солнечных
панелей Трент — сквозной «не вовремя». Сценарий сезона: `season1_script.txt`, выкладка `publish_s01.txt`.
Рисовка — манера «Ключевого сотрудника» (`props/kspix.py`, задник xAI + герои кодом, 2.5D) по просьбе владельца 23.11.2026; герои свои
(`engine/props/mdcast.py`, кит `mdkit.py`, антураж `mddecor.py`).
Чем герои отличаются от существующих: Гленн — «вешалка» (очень высокий, лошадиное лицо, флэт-топ, клетчатый халат, шорты-карго, носки
в шлёпанцах) — не похож ни на Дейла, Рэнди, Винса (US), ни на Эдика (груша); говорящий предмет — дверной звонок с объективом-глазом и
LED-бровью (не аллигатор, не индейка, не вывеска, не фикус); Трент — квадратный загорелый продавец в оранжевом пуховом жилете.
