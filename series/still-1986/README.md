# STILL 1986 (US) — Майами, 2026, но Винс живёт в 1986-м

Сценарий сезона: `season1_script.txt`. Дизайн: `design/philosophy.md`, `design/cast_sheet.png` (`design/cast_sheet.py`).
Риг: `engine/props/v86pix.py` (манера «Sunset Chrome»: закатный ключ + неоновый контровой, «жалюзи» вместо дизеринга),
`engine/props/v86cast.py` (Винс, Рей, машина, эвакуатор, счётчик, табличка), `engine/props/v86kit.py` (миры, свет, Фрэн-неон,
заголовки, обложки, вставки-экраны), `engine/props/v86decor.py` (антураж Ocean Drive).
Голоса: `voices.json` (Винс и Рей — Voice Library без слотов, Фрэн — Voice Design).

**Чем герои отличаются от всех существующих:** Винс — «перевёрнутый треугольник на зубочистках» (подплечники, маллет-химия,
полупрозрачные авиаторы), не похож ни на пузатого лысого Florida Man, ни на «кирпич на груше» Рэнди, ни на Дейла из Sunny Palms;
комментатор — не животное (кот, аллигатор, индейка), а неоновая вывеска, у которой «речь» видна вспышками трубок. Манера
освещения (закат + неон, двойной ободок, полосы-жалюзи) не повторяет ни один сериал канала.
