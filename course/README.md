# Курс «PIXEL VERSE · Мультстудия в кармане»

Продукт для продажи через Telegram-бота: как делать пиксельные мультсериалы через Claude Code.

- `out/01_Курс_Мультстудия_в_кармане.pdf` — основной курс (модули 0–9).
- `out/02_Промты_шпаргалка.pdf` — все промты и команды.
- `out/03_Чек-листы.pdf` — чек-листы этапов.
- `out/starter-kit.zip` — стартовый набор для репозитория покупателя (исходники в `starter-kit/`).

Пересборка: `python3 build.py [course|prompts|checklists]` (нужны `pip install markdown` и Playwright из окружения), архив: `cd starter-kit && zip -qr ../out/starter-kit.zip .`.
Исходники текста — `src/<doc>/*.md` (шорткоды описаны в `build.py`), оформление — `src/style.css`, схемы экранов — `src/ui.py`, картинки — `img/` (кадры из серий канала).
