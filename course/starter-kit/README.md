# Моя мультстудия

Стартовый набор курса «PIXEL VERSE: мультстудия в кармане». Пиксельные мультсериалы для Shorts, Reels и TikTok делает Claude Code.

- `CLAUDE.md` — главные правила для Claude (он читает их сам в начале каждой сессии).
- `docs/` — формула серии, стиль, звук, выкладка, задание на сборку движка.
- `.claude/skills/` — готовые команды: `/start`, `/new-series`, `/episode`, `/fix`, `/publish`, `/stats`, `/ship`.
- `setup.sh` — строки для Setup script облачной среды.
- `STATUS.md` — где мы остановились.

Первый запуск: открой Claude Code, выбери этот репозиторий и напиши «/start».
