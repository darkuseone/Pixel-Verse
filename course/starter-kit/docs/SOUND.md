# SOUND.md — голоса, звуки, музыка

## Голоса (ElevenLabs)
- Модель `eleven_v4` или новее (перед сезоном сверить с elevenlabs.io/docs).
- Голос героя создаётся один раз через **Voice Design**: возраст, тембр, темп, манера, акцент по смыслу героя («прокуренный бас мужчины 50 лет, говорит уверенно и громко, как старшина»). Детские голоса Voice Design не делает: подростка описывать как молодого взрослого.
- Из 3 превью владелец выбирает одно, голос сохраняется, id → `series/<slug>/voices.json`. **Голоса героев не меняются никогда.**
- Лимит своих голосов зависит от тарифа ElevenLabs. Если места нет — спросить владельца, какой старый голос удалить (перед удалением записать его описание и id в `docs/VOICES.md`).

## Как писать реплики (`episodes/epNN/lines.json`)
```json
{ "v1": ["valera", "[shocked, shouting] СКО́ЛЬКО?!"],
  "t1": ["tamara", "[bored, flat, chewing gum] Две́сти во́семьдесят де́вять."] }
```
- Тег эмоции в каждой реплике: `[shouting]`, `[deadpan]`, `[smug]`, `[sarcastic]`, `[furious]`, `[panicking]`, `[whining]`, `[whispering]`, `[sigh]`, `[laughs]`, `[pause]`.
- Шутка и сарказм играются голосом, а не читаются: контраст громкости (крик → скучный ответ) = смех.
- **Русский:** знак ударения U+0301 после ударной гласной во всех словах из 2+ слогов, «ё» писать. Ставить так, как говорит живой человек. Перед генерацией вычитать все ударения. В субтитрах ударения убирать.
- **Английский:** ударное слово КАПСОМ; трудные слова — IPA в слэшах; без многоточий (растягивают паузу).
- Плоский дубль перегенерировать один раз. Паузы внутри дубля вырезать (`engine/tighten.py`).

## Звуки
- У каждого сериала свой набор 15–25 реалистичных фоли-звуков (шаги, ткань, предметы, удары, дыхание) и 2 атмосферы-лупа (`series/<slug>/sfx/`). Звуки одного сериала в другом не использовать.
- Плоские «миди»-пищалки не ставить. Резкое ровное шипение (пар, спрей) пропускать через фильтр (lowpass ~5 кГц) и делать тихой подложкой.
- 8–15 точечных звуков на серию в ритм смены кадров; каждый поворот подчёркнут звуком; звук с 0 мс.

## Музыка
- Один мотив на серию, короткий луп ~15 с, дальше зацикливание с плавной склейкой.
- Бесплатно: синтез кодом (`engine/music.py`: бас, аккорды, простая мелодия, 8-битные тембры).
- Платно: короткий луп ElevenLabs Music (дорого: ~900 кредитов за минуту — только если код не справился).
- Чужие песни и треки нельзя (YouTube заберёт доход или заблокирует).
- 2–4 лупа на сериал, переиспользовать между сериями.

## Сведение
- Реплики по таймкодам, первый звук на 0 мс; музыка ≈0,25 без речи и ≈0,10 под речью (дакинг); атмосфера тихо.
- Итог **−14 LUFS, пик −1 dBTP** (двухпроходный `loudnorm`).

## Бюджет кредитов (ориентир)
- Реплика: ~5–15 кредитов. Серия (12–16 реплик): ~100–200.
- Новый звук: ~40–200 кредитов. Голос через Voice Design: ~100–200 разово.
- Пилот нового сериала дороже (голоса, звуки), следующие серии дешевле за счёт переиспользования.
- Перед платным вызовом проверить, что файла ещё нет и папка существует.
