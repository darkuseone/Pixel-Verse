# PUBLISH.md — выкладка и статистика

## Файл выкладки (`series/<slug>/publish_sNN.txt`, в конце сезона)
1. Время один раз сверху, по местному времени владельца, без округления (18:15, не 18:10). Порядок: YouTube → TikTok (+15 мин) → Instagram (+15 мин).
2. Одна серия в день, утром (утренний ролик крутится весь день). Второй ролик в день — вечером.
3. Блоки YouTube, TikTok, Instagram; в каждом серии 1–6. Каждая серия в каждой сети — один блок для копирования:
```
Название (YouTube ≤ 60 знаков, без спойлера поворота)
Описание: 2–3 предложения, последнее — вопрос-выбор для комментариев
#хэштег1 #хэштег2 #хэштег3 (3–5 штук)
```
4. Названия и описания разные для каждой сети (перефразировать). Ссылок в файле нет.
5. Если площадка спрашивает про ИИ-контент — следовать её правилам.

## Статистика (раз в неделю)
Владелец присылает цифры или скриншоты: просмотры, «продолжили смотреть» / пролистывания, средний процент просмотра, досмотр, лайки, комментарии, репосты, сохранения, подписки.
- Записать в `docs/STATS.md` (журнал по неделям, новые сверху), сводку по сериям.
- Найти секунду просадки кривой и причину.
- Обновить раздел «Главные выводы» и предложить 1–3 конкретные правки следующих серий.
- Сравнивать серии по вовлечённым просмотрам и «продолжили смотреть», а не только по публичным просмотрам.
