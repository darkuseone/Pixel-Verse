# ENGINE.md — как собрать движок мультстудии

Это техническое задание для Claude. Владелец не программист: он даёт команду «собери движок по docs/ENGINE.md», а ты строишь всё сам, по этапам, и после каждого этапа показываешь результат картинкой или видео.

Стек: **Python 3 + numpy + Pillow + ffmpeg**. Никаких тяжёлых библиотек, игровых движков и нейросетей для картинки. Всё рисуется кодом, чтобы стиль был узнаваемым и стабильным от серии к серии.

---

## Структура репозитория

```
engine/            движок (общий для всех сериалов)
  paths.py         пути проекта
  pix.py           пиксельный холст: фигуры с обводкой, штриховка, палитра
  rig.py           герой: голова, лицо, тело, руки, позы, мимика, рот в такт речи
  world.py         задники кодом: комнаты, улица, магазин; параллакс; свет
  decals.py        таблички, вывески, ценники, наклейки с автоподбором шрифта
  fx.py            частицы (пыль, снег, искры, пар), вспышка, тряска, мозаика
  text.py          текст-хук, плашка серии, субтитры-караоке, стикеры, плашка «ПОДПИШИСЬ!»
  tts.py           ElevenLabs: озвучка реплики, Voice Design, сохранение голоса
  sfx.py           ElevenLabs: звуки и атмосферы; проверка на «резкое шипение»
  music.py         музыкальный луп синтезом кодом (бесплатно)
  tighten.py       вырезать паузы из дубля (ffmpeg silencedetect)
  mix.py           сведение: реплики + звуки + музыка → −14 LUFS
  episode.py       каркас серии: таймлайн, планы, рендер по планам, обложка, CLI
  critic.py        машинный критик + контрольные листы
  fonts/           пиксельные шрифты с кириллицей (OFL), например Press Start 2P
series/<slug>/     сериал: README.md, STATUS.md, voices.json, design/, sfx/, music/, episodes/epNN/
build/             временные файлы (в .gitignore)
```

## Этапы (после каждого — показать владельцу и закоммитить)

### Этап 1. Пиксельный холст и первый герой
- Логический холст 360×640 (для 9:16), увеличение в 3× nearest до 1080×1920. Для крупных планов — двойное разрешение героя (герой рисуется на холсте 2× и увеличивается меньше), чтобы мимика не превращалась в «кашу»: один пиксель героя на экране не больше ~4 px.
- Примитивы: эллипс, капсула (палка с круглыми концами), многоугольник, все с тёмной обводкой 1 px и 2–3 тонами (свет/основной/тень). Ограниченная палитра.
- Герой (`rig.py`): описывается словарём (рост, ширина, палитра, причёска, атрибуты), рисуется функцией с параметрами: поза, взгляд, эмоция (`normal, shout, shock, angry, smug, sad, deadpan, panic`), открытость рта 0..1, моргание, дыхание.
- Лицо детально: белки, зрачки и блик, веки, брови (эмоция!), нос с тенью, рот с зубами и языком, щетина/морщины/румянец по герою.
- **Показать:** лист «герой в 6 эмоциях» (`design/cast_sheet.png`).

### Этап 2. Задник, надписи, свет
- `world.py`: задник кодом из слоёв (стена, пол, мебель, окно, улица), общая палитра, лёгкий параллакс. Камера: позиция, зум, плавный наезд/отъезд/панорама.
- Герой стоит на полу (контактная тень), масштаб совпадает с мебелью.
- `decals.py`: табличка с текстом подбирает самый крупный шрифт, который помещается с отступом; не помещается — короткий вариант. Пародийные надписи (объявление, ценник, «НЕ ПАРКОВАТЬСЯ»).
- Свет: общий тон локации + тёплые пятна от ламп.
- Если в окружении есть ключ xAI (`XAI_API_KEY`) и владелец разрешил — задник можно сгенерировать картинкой (без людей и без текста), затем пикселизовать и привести к палитре; надписи всё равно рисует код. Без ключа — только кодом.
- **Показать:** кадр 1080×1920 «герой в локации с 5+ табличками».

### Этап 3. Голос и рот
- `tts.py`: `POST /v1/text-to-speech/{voice_id}` (модель `eleven_v4` или новее, проверить в документации ElevenLabs), mp3 в `series/<slug>/voice/<id>.mp3`. Перед платным вызовом проверить, что папка существует. Готовый файл не генерировать заново.
- Ключ: если есть `ELEVENLABS_API_KEY` — заголовок `xi-api-key`; если нет — запрос без ключа (его подставит Network secret облачной среды).
- Voice Design: описание голоса → 3 превью → владелец выбирает → сохранить голос → id в `voices.json`. Лимит своих голосов зависит от тарифа: перед сохранением проверить место.
- Рот в такт: громкость речи по кадрам (ffmpeg → PCM → огибающая) → открытость рта 0..1.
- **Показать:** 5-секундный ролик, где герой говорит одну реплику со звуком.

### Этап 4. Текст и эффекты
- `text.py`: текст-хук (2–4 слова крупно по центру ~2 с), плашка «СЕЗОН N • СЕРИЯ N/6» слева вверху, субтитры-караоке по 1–3 слова (белые с чёрной обводкой, ударное слово цветом говорящего; не на лицах и не в нижних 20 %), стикеры (выскакивают и подпрыгивают), плашка «ПОДПИШИСЬ!» с колокольчиком за 1 с до конца.
- Субтитры без знаков ударения (U+0301 вырезать).
- `fx.py`: пыль/снег/искры/пар, вспышка, тряска, пиксельная мозаика-переход, линии скорости.
- **Показать:** кадр с субтитрами и стикером + кадр плашки подписки.

### Этап 5. Серия целиком
- `episode.py`: серия = `timeline.py` (длина `DUR`, моменты склеек `CUTS`, индекс поворота `TWIST`, тайминги реплик и звуков) + функции планов. Каждый план рисует кадр по времени `t`.
- CLI: `python3 epNN.py test 1.0 5.0 …` (контрольный лист мини-кадров), `frames t…` (полноразмерные кадры), `all` (рендер всех планов параллельно, 4 процесса, сегменты в `build/<slug>-epNN/`, склейка), `shots 3 7` (перерендер только этих планов).
- Обложка: отдельный `cover.py` → `cover.png` 1080×1920; вшивается в первые 0,1 с.
- `mix.py`: `adelay` по таймкодам, первый звук на 0 мс, музыка ≈0,25 без речи и ≈0,10 под речью, `amix normalize=0` → двухпроходный `loudnorm` до −14 LUFS / −1 dBTP; если аудио короче видео — `apad`.
- **Показать:** пилотная серия 30–35 с.

### Этап 6. Критик
- `critic.py`: рендерит середину каждого плана в контрольный лист (12 мини-кадров на картинку) и проверяет автоматически: длина 30–35 с, доля поворота 0,50–0,60, громкость около −14 LUFS, есть звук на 0 мс, плашка подписки в последнюю секунду, текст/субтитры не на лицах, надпись не обрезана краем кадра. Отчёт `episodes/epNN/critic.md`.

## Требования к качеству

- Кадр никогда не статичен: дыхание, моргание, частицы, движение камеры.
- Кадр физически возможен: ноги на полу, предметы на поверхностях, масштаб совпадает.
- Видно, кто говорит: рот двигается; у говорящего предмета (телефон, рация, экран) — волны или эквалайзер.
- Рендер серии 30 с — не дольше ~15 минут на 4 ядрах.
- Код переиспользуемый: каждый нарисованный предмет — функция в библиотеке реквизита, новая локация дешевле предыдущей.
