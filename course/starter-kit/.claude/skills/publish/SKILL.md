# /publish <slug> [сезон] — файл выкладки

1. Уточнить один раз (если неизвестно): город/часовой пояс владельца и дату первой серии.
2. Найти поиском актуальное лучшее время выкладки для рынка; одна серия в день утром.
3. Написать `series/<slug>/publish_sNN.txt` по `docs/PUBLISH.md`: время сверху; блоки YouTube → TikTok → Instagram; в каждом серии 1–6; названия и описания разные для каждой сети; последнее предложение описания — вопрос-выбор; 3–5 хэштегов; без ссылок.
4. Отправить файл владельцу в чат. `/ship`.
