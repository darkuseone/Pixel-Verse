# /stats — цифры → выводы → правки

1. Прочитать цифры со скриншотов/таблицы владельца. Непонятное — спросить, не выдумывать.
2. Записать неделю в `docs/STATS.md` (новые сверху): по каждой серии и сети — просмотры, «продолжили смотреть», средний % просмотра, досмотр, лайки, комментарии, репосты, сохранения, подписки; подписки на 1 000 просмотров.
3. Сравнить серии: что общего у лучших и худших (тема, хук, первый кадр, длина, поворот).
4. Найти секунду просадки кривой удержания (если есть скрин кривой) и её причину в сценарии.
5. Обновить «Главные выводы» в начале `docs/STATS.md`; удачный приём — в `docs/FORMULA.md` §9.
6. Ответ владельцу: 3–5 строк выводов + 1–3 конкретные правки для следующих серий. `/ship`.
