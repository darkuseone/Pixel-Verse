# /new-series [тема] — сериал от идеи до «ок»

1. **Рынок.** Если владелец не сказал язык/страну аудитории — один вопрос.
2. **Статистика.** Если есть `docs/STATS.md` — прочитать «Главные выводы» и учесть.
3. **Поиск юмора.** Веб-поиск: актуальные мемы, наболевшие темы этой недели, вечные бытовые боли рынка. Дописать раздел с датой в `docs/HUMOR.md`. Проверить «Уже использовано».
4. **Концепция:** название сериала, логлайн, дуэт героев (самоуверенный лузер + циничный комментатор), мир (знакомые всем локации), коронные фразы, сквозной предмет-счётчик сезона, стиль обложки (шрифт, палитра, табличка).
5. **Герои.** Модельный лист кодом `series/<slug>/design/cast_sheet.png`: силуэты, палитры, 5 эмоций, атрибуты, реквизит. Сверить с героями других сериалов — не должны быть похожи. Отправить картинку владельцу.
6. **Сценарий сезона** одним файлом `series/<slug>/season1_script.txt` по `docs/FORMULA.md`: по каждой из 6 серий — название, хук (первый кадр + текст-хук + первая реплика), биты с таймкодами и репликами (теги эмоций), поворот на 50–60 % с типом из каталога и уликой, кнопка, петля, вопрос-выбор, «отправь тому, у кого…». Серия 5 — пик, серия 6 — развязка + крючок на сезон 2. В конце — чем сценарий бьёт по удержанию.
7. Отправить файл владельцу в чат + 3–4 строки сути. **Ждать «ок»**. До «ок» голоса и звуки не генерировать (кроме случая «делай сам»).
8. После «ок»: создать `series/<slug>/README.md`, `STATUS.md`, `voices.json`; голоса через Voice Design (3 превью на героя → владелец выбирает); `/ship`.
