# /ship "<сообщение>" — сохранить в main

1. `git status --short`. В git идут: код, `final.mp4` (≤ 95 МБ), обложки, mp3 реплик/звуков/музыки, документы. Не идут: `build/`, временные wav.
2. `git add` нужных путей → `git commit -m "<что сделано, по-русски>"`.
3. `git push -u origin <рабочая ветка>`. Сетевая ошибка — до 4 повторов (2, 4, 8, 16 с).
4. Создать pull request в `main` и сразу смёржить (squash) — владелец просит, чтобы всё готовое было в `main`.
5. Если PR этой ветки уже смёржен — новую работу начинать с свежего `main` (`git fetch origin main && git checkout -B <ветка> origin/main`).
6. Владельцу — одна строка: «Сохранено в main».
