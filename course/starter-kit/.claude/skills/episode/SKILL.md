# /episode <slug> <N|rest> — серия от реплик до отправки

Читать только `series/<slug>/STATUS.md` и сценарий своей серии. Для `rest` — серии подряд без новых согласований, после каждой отправка и `/ship`.

1. **Реплики** `episodes/epNN/lines.json`: тег эмоции в каждой, РУ — ударения U+0301 во всех словах из 2+ слогов, EN — КАПС ударного слова. Вычитать ударения. Голоса только из `voices.json`.
2. **Озвучка** `engine/tts.py` → `engine/tighten.py`. Готовые реплики не перегенерировать.
3. **Звук:** сначала `series/<slug>/sfx/`, новое генерировать только если нет подходящего, сразу класть в библиотеку с понятным именем. Музыка — лупы сериала.
4. **Локации:** задник + 5–10 местных табличек/наклеек/реквизита + анимированная мелочь. Надписи внутри табличек.
5. **Код серии** `epNN.py` + `timeline.py` (DUR, CUTS, TWIST, тайминги реплик и звуков). Плашка «ПОДПИШИСЬ!» за 1 с до конца, вопрос-выбор стикером на последние 2 с.
6. **Обложка** `cover.py` → `cover.png` + `cover_grid.png` (до финального рендера, вшивается в 0,1 с).
7. **Контрольный лист** `python3 epNN.py test …` — середина каждого плана; посмотреть самому: лица, надписи, субтитры не на лицах, кто говорит.
8. **Рендер** `python3 epNN.py all` в фоне → `engine/mix.py` (−14 LUFS).
9. **Критик** `python3 engine/critic.py series/<slug>/episodes/epNN` → правки → перерендер только затронутых планов.
10. **Чек** (`docs/FORMULA.md` §7): длина 30–35 с, поворот 50–60 %, звук с 0 мс, кнопка без хвоста, петля, громкость.
11. **Сдача:** `final.mp4` + `cover.png` + `script.md` (с долей поворота) + `lines.json` + код в `episodes/epNN/`. Отправить владельцу в чат **только `final.mp4` и `cover.png`** + 2–3 строки (кредиты, что переиспользовано, что подрезал). `/ship`. Обновить `STATUS.md` сериала.
