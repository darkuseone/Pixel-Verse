# /start — войти в работу дёшево

1. Прочитать `STATUS.md` и, если задача про сериал, `series/<slug>/STATUS.md`. Больше ничего целиком не читать.
2. Если в стартовом наборе лежит `starter-kit.zip` (владелец загрузил архив) — распаковать его в корень репозитория, удалить архив, закоммитить и сказать владельцу «стартовый набор на месте».
3. Окружение одной командой: `ffmpeg -version | head -1; python3 -c "import numpy, PIL; print('python ok')"`; ElevenLabs: `curl -s -o /dev/null -w "%{http_code}" https://api.elevenlabs.io/v1/user/subscription` (с заголовком `xi-api-key`, если есть переменная `ELEVENLABS_API_KEY`). Ключи не печатать.
   - нет ffmpeg/numpy → поставить и напомнить владельцу про Setup script (модуль 2 курса);
   - ElevenLabs не 200 → объяснить простыми словами, что ключ не подставился, и где его добавить (Network secret, модуль 2).
4. Если нет папки `engine/` — предложить: «Собираю движок по docs/ENGINE.md, это займёт одну сессию».
5. Выбрать команду:

| Владелец просит | Команда |
|---|---|
| новый сериал / сезон | `/new-series` |
| пилот, серию N, остальные серии | `/episode` |
| правки к готовой серии | `/fix` |
| файл выкладки | `/publish` |
| статистика, скриншоты | `/stats` |
| сохранить, отправить в main | `/ship` |

6. Ответ владельцу: 2–3 строки — что готово, что делаем дальше.
