# Команды студии

| Команда | Что делает | Когда |
|---|---|---|
| `/start` | Читает, где остановились, проверяет окружение, предлагает следующий шаг | В начале каждой сессии |
| `/new-series` | Ищет мемы, придумывает героев, пишет сценарий сезона | Новый сериал или сезон |
| `/episode <сериал> 1` | Делает одну серию от реплик до видео | Пилот, любая серия |
| `/episode <сериал> rest` | Делает все оставшиеся серии подряд | После «ок» на пилот |
| `/fix <сериал> <N>` | Правит готовую серию, перерисовывает только нужное | Есть замечания |
| `/publish <сериал> <сезон>` | Файл выкладки: названия, описания, хэштеги, время | Конец сезона |
| `/stats` | Разбирает статистику, даёт правки | Раз в неделю |
| `/ship` | Сохраняет всё на GitHub в main | Если Claude забыл сохранить |

# Настройка (один раз)

:::prompt Setup script — в настройки среды, не в чат
#!/bin/bash
apt-get update -qq && apt-get install -y -qq ffmpeg > /dev/null
python3 -m pip install -q numpy pillow || python3 -m pip install -q --break-system-packages numpy pillow
:::

:::prompt Промт 1 · распаковать стартовый набор и проверить
Привет! Это мой новый репозиторий для мультстудии. В корне лежит starter-kit.zip — стартовый набор курса PIXEL VERSE.
1) Распакуй архив в корень репозитория (если внутри одна папка — перенеси её содержимое в корень, включая скрытую папку .claude), удали архив и сохрани изменения в main.
2) Прочитай CLAUDE.md и выполни /start: проверь ffmpeg, Python (numpy, pillow) и доступ к ElevenLabs. Ключи не печатай.
3) Ответь мне простыми словами, что работает, а что нет. Я не программист.
:::

:::prompt Промт 2 · собрать движок
Собери движок по docs/ENGINE.md. Работай по этапам: после каждого этапа присылай мне картинку или видео и сохраняй всё в main.
Мой рынок: <русскоязычная аудитория (Россия и СНГ) / США>. Для проверки придумай пробного героя, которого не будет в сериалах: <усатый вахтёр в фуражке, ворчливый, голос — прокуренный бас>.
Если лимит закончится посреди работы — обнови STATUS.md, чтобы потом продолжить с того же места.
:::

:::prompt Продолжить после лимита
Продолжай с того места, где остановились. Сначала /start.
:::

# Сериал

:::prompt Придумать сериал
/new-series Придумай мультсериал для <русскоязычной аудитории>. Тема: <бытовые боли взрослого человека — работа, начальник, коммуналка, цены, соседи>. Нужен дуэт: самоуверенный лузер и циничный комментатор. В сезоне 6 серий, в каждой своя боль, общая нить — герои. Сначала предложи 3 концепции на выбор по 4 строки каждая.
:::

:::prompt Выбрать концепцию
Делаем концепцию <2>, но <комментатор — не кот, а говорящий холодильник>. Нарисуй модельный лист героев и пришли сценарий сезона одним файлом.
:::

:::prompt Описать героя самому
Главный герой — <имя>, <возраст>, <профессия/роль>. Силуэт: <груша / кочерга / пончик>. Атрибуты: <фуражка на два размера меньше, рация как пистолет>. Смешная деталь: <усы-щётка, пластырь на носу>. Характер: <самоуверенный, считает себя спецназом>. Коронная фраза: «<У меня всё под контролем!>».
Комментатор — <голубь с вывески>. Говорит одно слово в камеру, сухо.
:::

:::prompt Правки к сценарию
Серии <1, 2, 4, 6> — ок. Серия <3>: поворот предсказуемый, придумай 3 других варианта из каталога поворотов, которых ещё не было в сезоне. Серия <5>: хук скучный — нужен крик и предмет конфликта в первом кадре. Остальное оставь.
:::

:::prompt Описание голоса
Голос для <героя>: <мужчина 50 лет, прокуренный бас с хрипотцой, говорит громко и уверенно, как старшина на плацу, растягивает гласные, когда возмущается>. Язык: <русский>, акцент: <нет>. Сделай 3 варианта и пришли мне послушать.
:::

# Серии

:::prompt Пилот
/episode <сериал> 1
:::

:::prompt Весь сезон
Пилот ок! /episode <сериал> rest — сделай серии 2–6 подряд без новых согласований. После каждой серии присылай final.mp4 и cover.png и сохраняй в main.
:::

:::prompt Показать кадры до рендера
Перед рендером серии <N> пришли мне контрольный лист кадров. Рендер — после моего «ок».
:::

# Правки

:::prompt Правки к серии
/fix <сериал> <N>
1) <0–2 с>: <текст-хук мелкий, сделай крупнее>.
2) <14 с>: <реплика слишком быстрая, перегенерируй медленнее и ленивее>.
3) <26 с>: <после поворота добавь вспышку и звук кассы>.
Остальное ок.
:::

:::prompt Исправить ударение
Серия <2>, реплика <кассирши> на <7>-й секунде: ударение «<по пра́вде>», а она сказала неправильно. Перегенерируй только эту реплику.
:::

:::prompt Усилить шутку
Кнопка серии <N> слабая. Дай 3 варианта последней реплики <кота>: короче, суше, с ударом в последнем слове. Я выберу.
:::

:::prompt Вернуть старую версию
Верни серию <3> к версии, которую ты присылал первой. Найди её в истории GitHub.
:::

# Выкладка и статистика

:::prompt Файл выкладки
/publish <сериал> <1>
Я живу в <Москве (UTC+3)>, первую серию выкладываем <завтра>.
:::

:::prompt Разбор статистики
/stats Вот статистика за неделю по сериям <1–6> (скриншоты прикрепил). Найди, на какой секунде падает удержание, что общего у лучших и худших серий, и дай 3 конкретные правки для следующего сезона.
:::

:::prompt Второй сезон
/new-series Сезон 2 сериала <название>. Те же герои и голоса. Учти выводы из docs/STATS.md. Новые 6 бытовых болей, новые типы поворотов, крючок в конце сезона 1 должен получить ответ в первой серии.
:::
