# 1.1 GitHub — шкаф для файлов

GitHub — сайт, где хранятся проекты программистов. Для нас это облачная папка: там будут лежать герои, серии и все версии файлов. Бесплатно.

:::steps
1. Открой **github.com** и нажми <span class="btn">Sign up</span>.
2. Введи почту, придумай пароль и имя пользователя (ник латиницей, например `ivan-cartoons`). Ник будет в адресах, выбирай без смешных опечаток.
3. Пройди проверку «я не робот» и введи код из письма, которое придёт на почту.
4. Если GitHub спросит про тариф — выбирай <span class="btn">Free</span>. Вопросы про команду и опыт можно пропустить.
:::

:::ok Что должно получиться
Ты на github.com, в правом верхнем углу твой аватар. Ник запиши: он понадобится в модуле 2.
:::

# 1.2 Claude — твоя команда

:::steps
1. Открой **claude.ai** и войди: через Google-аккаунт или по почте (придёт код).
2. Нажми на своё имя внизу слева → **Settings** → **Billing** (или кнопку <span class="btn">Upgrade</span>).
3. Выбери тариф **Pro** и оплати картой. Годовая оплата выходит дешевле, но для старта хватит месяца.
4. Поставь приложение **Claude** на телефон (App Store или Google Play) и войди тем же аккаунтом. В приложении есть вкладка **Code** — это и есть Claude Code.
:::

:::ok Что должно получиться
На claude.ai в настройках написано, что у тебя план Pro. Адрес **claude.ai/code** открывается и предлагает подключить GitHub (это сделаем в модуле 2).
:::

:::fix Если не получилось
- **Не проходит оплата.** Банк может блокировать зарубежные платежи: включи их в приложении банка или попробуй другую карту.
- **Пишет, что сервис недоступен в регионе.** Значит, твоей страны нет в списке поддерживаемых (модуль 0). Обходить это ограничение курс не учит.
:::

# 1.3 ElevenLabs — голоса героев

:::steps
1. Открой **elevenlabs.io**, нажми <span class="btn">Sign up</span> и зарегистрируйся (Google или почта).
2. Открой раздел подписки (**Subscription** или **Upgrade** в меню профиля) и выбери тариф **Starter**.
3. Создай ключ API (см. схему ниже): в меню слева **Developers** → **API Keys** → <span class="btn">Create Key</span>. Назови его `claude-cartoons`.
4. Если есть настройки доступа ключа — разреши всё, что про голос, звуки и музыку: Text to Speech, Voices, Sound Effects, Music, User (чтение).
5. Нажми **Copy** и вставь ключ в заметки на телефоне. Ключ начинается с `sk_`. **Показывается он один раз.**
:::

{{ui:el_key}}

:::warn Ключ — это пароль от твоего баланса
- Никому не отправляй ключ и не публикуй скриншоты с ним.
- **Никогда не вставляй ключ в чат с Claude.** В модуле 2 мы положим его в специальное защищённое место, где Claude его даже не видит.
- Потерял или засветил — удали ключ в ElevenLabs и создай новый.
:::

:::ok Что должно получиться
Тариф Starter активен (вверху видно около 30 000 кредитов), ключ `sk_…` лежит в твоих заметках.
:::

:::tip Можно ли начать бесплатно
Можно пройти модули 1–3 на бесплатном тарифе ElevenLabs (10 000 кредитов в месяц): этого хватит, чтобы Claude собрал студию и озвучил пробного героя. Но для выкладки на монетизированный канал нужен платный тариф с коммерческой лицензией.
:::
