# 2.1 Репозиторий — папка проекта

**Репозиторий** — это папка проекта на GitHub. Особенность в том, что она помнит каждую версию каждого файла. Claude сохраняет туда работу после каждой серии, а ты можешь в любой момент вернуться к любой версии.

:::steps
1. Открой **github.com/new** (или нажми **+** вверху справа → **New repository**).
2. В поле **Repository name** впиши `my-cartoons`.
3. Выбери **Private** — проект будет виден только тебе.
4. Включи **Add README** — так в репозитории сразу появится первый файл.
5. Нажми <span class="btn green">Create repository</span>.
:::

{{ui:github_new}}

:::ok Что должно получиться
Открылась страница `github.com/твой-ник/my-cartoons` с одним файлом `README.md`.
:::

# 2.2 Кладём стартовый набор

**Стартовый набор** (`starter-kit.zip`) идёт вместе с курсом. Внутри — правила для Claude, формула серии, описание стиля и готовые команды. Именно он превращает обычного Claude в мультстудию. Распаковывать его не нужно: загрузи архив целиком, Claude распакует сам.

:::steps
1. Скачай `starter-kit.zip` из бота, где купил курс, на телефон или компьютер.
2. На странице репозитория нажми **Add file** → **Upload files**.
3. Перетащи архив в окно (на телефоне — нажми **choose your files** и выбери архив в «Файлах» или «Загрузках»).
4. Подожди, пока файл загрузится, и нажми <span class="btn green">Commit changes</span>.
:::

{{ui:github_upload}}

:::ok Что должно получиться
В репозитории два файла: `README.md` и `starter-kit.zip`.
:::

# 2.3 Подключаем Claude Code к GitHub

Claude должен получить доступ к твоему репозиторию. Это делается один раз.

:::steps
1. Открой **claude.ai/code** (на телефоне — вкладка **Code** в приложении Claude).
2. Нажми кнопку входа через GitHub и подтверди доступ на странице GitHub (**Authorize**).
3. Установи приложение **Claude** на GitHub. Если Claude сам не предложил, открой **github.com/apps/claude** → <span class="btn">Install</span>.
4. На вопрос, к каким репозиториям дать доступ, выбери **Only select repositories** → `my-cartoons` → <span class="btn green">Install</span>. Без этого шага Claude не увидит приватный репозиторий.
5. Вернись на claude.ai/code. Для тарифа Pro облачная среда **Default** создаётся сама.
:::

:::ok Что должно получиться
На claude.ai/code под полем ввода есть кнопка выбора репозитория, и в списке есть `my-cartoons`.
:::

:::fix Если репозитория нет в списке
Приложение Claude на GitHub не установлено на этот репозиторий. Открой **github.com/apps/claude** → **Configure** → добавь `my-cartoons` в список и сохрани. Обнови страницу claude.ai/code.
:::

# 2.4 Настраиваем облачный компьютер

Каждая сессия Claude Code работает на отдельном облачном компьютере. Его настройки называются **облачной средой** (environment). Нам нужно две вещи: чтобы на компьютере был **ffmpeg** (программа для сборки видео) и чтобы Claude мог звонить в ElevenLabs по твоему ключу.

**Как открыть настройки:** на экране новой сессии нажми первую кнопку под полем ввода (среда, обычно **Default**) → наведи на строку **Default** (на телефоне — нажми на неё) → нажми шестерёнку справа. Откроется окно **Edit cloud environment**.

{{ui:env_dialog}}

## Шаг А. Setup script — что установить

Setup script — это короткая инструкция, которую облачный компьютер выполняет перед каждой сессией. Строки лежат в стартовом наборе в файле `setup.sh`, но проще скопировать отсюда.

:::steps
1. В окне настроек нажми **Setup script**.
2. Вставь три строки из блока ниже.
3. Нажми <span class="btn">Save changes</span>.
:::

:::prompt Setup script (вставить в настройки среды, а не в чат)
#!/bin/bash
apt-get update -qq && apt-get install -y -qq ffmpeg > /dev/null
python3 -m pip install -q numpy pillow || python3 -m pip install -q --break-system-packages numpy pillow
:::

## Шаг Б. Network secret — ключ ElevenLabs

**Network secret** — защищённое хранилище ключей. Ключ хранится вне облачного компьютера и сам подставляется в запросы к ElevenLabs. Claude им пользуется, но не видит его, поэтому ключ не утечёт ни в чат, ни в файлы.

:::steps
1. В окне настроек нажми **Network secrets** → **Add secret**.
2. **Secret type** оставь как есть (**Bearer**).
3. **Name:** `ElevenLabs`.
4. **Allowed websites:** `api.elevenlabs.io`.
5. **Custom headers:** в первом поле (Name) сотри `Authorization` и впиши `xi-api-key`. Поле **Prefix** очисти, чтобы оно было пустым. В поле **Value** вставь свой ключ `sk_…` из заметок.
6. Нажми **Add**. Секрет появится в списке.
:::

{{ui:secret_form}}

:::warn Не перепутай заголовок
ElevenLabs принимает ключ в заголовке `xi-api-key` без всякого префикса. Если оставить `Authorization` и `Bearer`, голоса работать не будут.
:::

:::fix Если раздела Network secrets нет
Запасной способ. В окне настроек открой **Environment variables** и впиши одну строку: `ELEVENLABS_API_KEY=sk_твой_ключ`. Потом **Network access** → **Custom** → в **Allowed domains** впиши `api.elevenlabs.io` и оставь галочку «Also include default list of common package managers». Сохрани. Этот способ проще, но ключ виден программам внутри облачного компьютера.
:::

:::ok Что должно получиться
В окне среды: в Setup script три строки, в Network secrets — один секрет «ElevenLabs» для `api.elevenlabs.io`. Новые сессии подхватят настройки сами.
:::

:::tip Проверять будем в модуле 3
Первая же команда `/start` проверит всё: ffmpeg, Python и ключ ElevenLabs. Если что-то не так, Claude скажет простыми словами, что именно.
:::
