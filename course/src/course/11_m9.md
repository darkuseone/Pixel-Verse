# Как растянуть лимит Claude

Лимит тратится на две вещи: сколько Claude **читает** и сколько **пишет и пересматривает**. Стартовый набор уже настроен на экономию, но вот что зависит от тебя:

- **Начинай сессию с `/start`.** Claude читает короткий файл состояния вместо всей истории проекта.
- **Одна сессия — одна задача.** Сделал сезон — начни новую сессию для следующего. Длинная сессия с сотней сообщений тратит больше: Claude каждый раз «перечитывает» весь разговор.
- **Правки — пачкой.** Пять замечаний одним сообщением дешевле, чем пять сообщений по одному.
- **Не проси пересобрать всё.** «Перерендери только 7-й план» вместо «переделай серию».
- **Не держи окно пустым.** 5-часовое окно запускается с первого сообщения. Садись работать, когда есть на что потратить окно целиком: например, на сезон.
- **Смотри остаток** на странице Settings → Usage.

:::tip Модель
Для сборки движка и сценариев бери самую сильную модель. Если лимит кончается слишком быстро, попробуй рутинные серии (когда сценарий уже одобрен) делать на модели попроще (например, Sonnet): она тратит лимит медленнее. Качество проверяй на пилоте.
:::

# Частые ошибки

| Что видишь | Что значит | Что делать |
|---|---|---|
| «ffmpeg: command not found» | На облачном компьютере нет программы для видео | Проверь Setup script (модуль 2, шаг А), начни новую сессию |
| ElevenLabs: 401 / Unauthorized | Ключ не подставился | Проверь Network secret: `api.elevenlabs.io`, заголовок `xi-api-key`, префикс пустой. Новая сессия |
| ElevenLabs: quota / not enough credits | Кончились кредиты | Подожди обновления месяца или перейди на тариф выше |
| ElevenLabs: voice limit | Кончились слоты своих голосов | Скажи Claude, какой старый голос можно удалить |
| «Usage limit reached» | Кончилось 5-часовое окно | Подожди сброса, потом «продолжай» |
| «Session expired» / сессия спит | Облачный компьютер выключился от бездействия | Открой сессию из списка — разговор восстановится. Несохранённую работу Claude переделает |
| Claude «забыл», что делал | Новая сессия не знает историю | `/start` — он прочитает STATUS.md |
| Нет репозитория в списке | Приложение Claude не установлено на репозиторий | github.com/apps/claude → Configure → добавь репозиторий |
| Видео не скачивается на телефон | Файл большой или браузер не умеет | Открой файл на GitHub → Download raw file, или попроси Claude «сожми видео до 30 МБ» |

:::fix Универсальный рецепт
Если непонятно, что случилось, отправь Claude: «Что-то пошло не так. Объясни простыми словами, что случилось и что мне нажать». Приложи скриншот, если ошибка на экране.
:::

# Задники через xAI (необязательно)

У автора курса задники рисует нейросеть xAI (Grok Imagine), а код пикселизует их и дорисовывает надписи, героев и свет. Так мир получается богаче. Это не подписка, а оплата за использование: около $0,06 за картинку, 2–3 задника на серию, то есть $1–3 в месяц.

:::steps
1. Зарегистрируйся на **console.x.ai** и пополни баланс на $5.
2. Создай API-ключ.
3. В настройках среды Claude Code добавь ещё один Network secret: сайт `api.x.ai`, заголовок `Authorization`, префикс `Bearer`, значение — ключ xAI.
4. Напиши Claude: «Подключи задники xAI по ENGINE.md: без людей и текста, потом пикселизация и палитра сериала».
:::

# Вопросы и ответы

**Нужно ли уметь программировать?** Нет. Весь код пишет Claude. Тебе нужно уметь копировать текст, загружать файл на сайт и формулировать, что тебе не нравится.

**Можно ли всё делать только с телефона?** Да. Настройку (модули 1–2) удобнее пройти в браузере, но и с телефона она делается: открывай сайты GitHub и claude.ai в браузере телефона. Дальше вся работа — в приложении Claude, вкладка Code.

**А с компьютера?** Открой claude.ai/code в браузере или поставь приложение Claude для компьютера и выбери облачную среду. Это тот же облачный Claude Code, что и на телефоне. Продвинутые пользователи могут поставить Claude Code локально, но для курса это не нужно.

**Сколько времени уходит на серию?** У Claude — 20–40 минут. У тебя — 5 минут: посмотреть и написать «ок» или правки.

**Можно делать мультики на английском для США?** Да. Скажи Claude, что рынок — США, и он будет искать американские мемы, писать на американском английском и делать голоса с нужными акцентами. Базы юмора разных рынков не смешивай.

**Можно ли монетизировать?** Видео и код твои. Голоса на платном тарифе ElevenLabs идут с коммерческой лицензией. Музыка своя. Проверяй правила монетизации каждой площадки: они требуют оригинальности, и наш формат её даёт.

**Могу ли я сделать мультик про известного блогера или политика?** Нет. Реальных людей, войну, религию и трагедии не трогаем — это и правила площадок, и правило курса.

**Сколько сериалов можно вести одновременно?** Сколько хватит лимита и голосов. На тарифе ElevenLabs Starter до 10 своих голосов — это 3–4 сериала с героями по 2–3 человека.

**Что дальше после первого сезона?** Второй сезон с теми же героями (команда `/new-series сезон 2`), новый сериал с другими героями или длинная 16:9 версия сезона для YouTube.

# Словарик

|---|---|
| Репозиторий | Папка проекта на GitHub, которая помнит все версии файлов |
| Коммит | Сохранённый снимок файлов с подписью «что изменилось» |
| Ветка, main | Параллельная версия проекта; main — главная, «чистовик» |
| Pull request (PR) | Заявка «влить изменения в main». Claude делает и вливает сам |

| API-ключ | Пароль, по которому программа пользуется сервисом от твоего имени |
| Кредиты | Внутренняя валюта ElevenLabs: на них озвучка и звуки |
