# 3.1 Как устроена сессия

**Сессия** — это один разговор с Claude Code. У каждой сессии свой облачный компьютер, на который Claude скачивает твой репозиторий. Всё, что он сделал, он сохраняет обратно на GitHub — поэтому следующая сессия начинает с того места, где закончилась предыдущая.

Перед первым сообщением выбери под полем ввода:

| Кнопка | Что выбрать | Почему |
|---|---|---|
| Среда | **Default** | Ту, что настроили в модуле 2 |
| Репозиторий | **my-cartoons** | Твоя мастерская |
| Режим | **Auto**, если есть, иначе **Accept edits** | Claude работает сам и не спрашивает разрешения на каждый файл |
| Модель | Самая сильная из доступных (у автора — **Opus**) | Сборка движка — самая сложная работа курса |

:::tip Телефон или компьютер
Сессия живёт в облаке. Можно начать на компьютере, закрыть ноутбук и продолжить с телефона — разговор и файлы те же. Закрыл приложение — Claude продолжает работать.
:::

# 3.2 Промт 1 — распаковать и проверить

Начни новую сессию и отправь этот текст целиком:

:::prompt Промт 1 · первое сообщение в новом репозитории
Привет! Это мой новый репозиторий для мультстудии. В корне лежит starter-kit.zip — стартовый набор курса PIXEL VERSE.
1) Распакуй архив в корень репозитория (если внутри одна папка — перенеси её содержимое в корень, включая скрытую папку .claude), удали архив и сохрани изменения в main.
2) Прочитай CLAUDE.md и выполни /start: проверь ffmpeg, Python (numpy, pillow) и доступ к ElevenLabs. Ключи не печатай.
3) Ответь мне простыми словами, что работает, а что нет. Я не программист.
:::

:::ok Что должно получиться
Через 2–5 минут Claude пишет что-то вроде: «Стартовый набор распакован и сохранён. ffmpeg есть, Python есть, ElevenLabs отвечает — ключ работает. Движка ещё нет: следующий шаг — собрать его». На GitHub в репозитории появились `CLAUDE.md`, папки `docs`, `series`, `.claude`.
:::

:::fix Если не получилось
- **«ffmpeg не найден».** Setup script не сохранился или ещё не применился. Проверь его в настройках среды (модуль 2, шаг А) и начни **новую** сессию — старая не перечитывает скрипт.
- **«ElevenLabs отвечает 401».** Ключ не подставляется. Проверь секрет: сайт `api.elevenlabs.io`, заголовок `xi-api-key`, префикс пустой (модуль 2, шаг Б). После исправления — новая сессия.
- **«Не могу сохранить в main» / нет доступа к репозиторию.** Приложение Claude на GitHub не установлено на `my-cartoons` (модуль 2.3).
:::

# 3.3 Промт 2 — собрать студию

Теперь главное: Claude пишет движок — программу, которая рисует героев, озвучивает их, двигает камеру и собирает видео. Подробное задание лежит в стартовом наборе (`docs/ENGINE.md`), поэтому промт короткий.

:::prompt Промт 2 · собрать движок
Собери движок по docs/ENGINE.md. Работай по этапам: после каждого этапа присылай мне картинку или видео и сохраняй всё в main.
Мой рынок: русскоязычная аудитория (Россия и СНГ). Для проверки придумай пробного героя, которого не будет в сериалах: усатый вахтёр в фуражке, ворчливый, голос — прокуренный бас.
Если лимит закончится посреди работы — обнови STATUS.md, чтобы потом продолжить с того же места.
:::

Дальше Claude работает сам. Можешь закрыть приложение и заниматься своими делами. Примерно раз в 20–40 минут он будет присылать результат этапа:

<div class="flow c5">
<div><b>Этап 1</b>Модельный лист: вахтёр в шести эмоциях</div>
<div><b>Этап 2</b>Кадр: вахтёр в проходной с табличками</div>
<div><b>Этап 3</b>Голос: 3 варианта баса на выбор, потом видео, где он говорит</div>
<div><b>Этап 4</b>Субтитры, стикер и плашка «ПОДПИШИСЬ!»</div>
<div><b>Этап 5–6</b>Проба на 10 секунд и машинный критик</div>
</div>

:::warn Этап 3 — твой выбор голоса
Claude создаст три варианта голоса и попросит выбрать. Послушай и ответь «второй». Голос героя потом не меняется никогда, поэтому выбирай внимательно.
:::

**Как давать обратную связь по этапам.** Если тебе что-то не нравится, скажи прямо и конкретно, Claude поправит до перехода к следующему этапу:

- «Лицо слишком мелкое, на телефоне не видно мимики. Сделай крупнее глаза и рот».
- «Таблички нечитаемые, шрифт слишком мелкий».
- «Голос слишком спокойный, нужен злее и с хрипотцой».

# 3.4 Где смотреть результат

# 3.5 Если закончился лимит

Посреди сборки может закончиться 5-часовое окно. Это нормально: сборка движка — самая тяжёлая работа курса.

:::steps
1. Claude успеет сохранить работу (он делает это после каждого этапа).
2. Дождись сброса окна. Время сброса видно на странице **Settings → Usage**.
3. Открой ту же сессию из списка слева (или начни новую с тем же репозиторием) и напиши: «Продолжай сборку движка с того места, где остановились».
:::

{{ui:usage}}

:::ok Что должно получиться в конце модуля
- В репозитории есть папка `engine` и пробное видео.
- Ты видел модельный лист вахтёра, кадр в локации и 10-секундное видео, где он говорит выбранным голосом, с субтитрами и звуком.
- В `STATUS.md` написано, что движок собран.

Студия готова. Дальше — самое интересное: стиль, сценарий и первый сериал.
:::
