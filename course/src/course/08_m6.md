# Голос героя создаётся один раз

ElevenLabs умеет делать голос по текстовому описанию (**Voice Design**). Claude пишет описание, получает три варианта, присылает тебе — ты выбираешь. Дальше этот голос закреплён за героем навсегда: зритель узнаёт героя по голосу.

:::prompt Пример описания голоса
Мужчина 50 лет, прокуренный бас с хрипотцой, говорит громко и уверенно, как старшина на плацу. Немного растягивает гласные, когда возмущается. Русский язык, без акцента.
:::

- Описывай **возраст, тембр, темп, манеру, акцент** — по характеру героя. Акцент по смыслу (деревенский, кавказский, южный) делает героя смешнее.
- Детские голоса ElevenLabs не создаёт. Подростка описывай как «молодой взрослый, 18–20 лет».
- На тарифе Starter до 10 своих голосов. Если место кончится, Claude спросит, какой старый голос удалить.

# Эмоции — тегами

В каждой реплике Claude ставит тег эмоции в квадратных скобках. Так шутку «играют», а не читают.

| Тег | Как звучит | Когда |
|---|---|---|
| `[shouting]` | Крик | Хук, возмущение |
| `[deadpan]` | Мёртвый ровный тон | Сухой ответ системы, комментатор |
| `[smug]` | Самодовольно | Коронная фраза лузера |
| `[sarcastic]` | С сарказмом | Добивание |
| `[panicking]` | В панике | Поворот |
| `[sigh]` | Вздох | Перед скучным ответом |
| `[whispering]` | Шёпот | Тайный план |
| `[laughs]` | Смешок | Злорадство |

**Контраст громкости = смех.** Герой орёт `[shouting]` — ему отвечают `[deadpan, bored, chewing gum]`. Это самый простой рабочий приём.

## Ударения

Нейросеть иногда ставит ударение неправильно. Поэтому в русских репликах Claude ставит знак ударения над ударной гласной в каждом слове: «СКО́ЛЬКО?!». В субтитрах этих знаков нет — они только для озвучки.

:::fix Если голос ошибся или звучит плоско
Напиши конкретно, какая реплика и что не так. Claude перегенерирует только её:

«Серия 2, реплика кассирши на 7-й секунде: ударение "по пра́вде", а она сказала "по правде́". И сделай голос ленивее, как будто она жуёт жвачку.»
:::

# Звук «как в студии»

- **Звук с первой миллисекунды.** Тишина в начале — это пролистывание.
- **Атмосфера под каждой локацией:** гул магазина, шум подъезда, ветер на улице. Тихо, фоном.
- **8–15 точечных звуков на серию:** шаги, удары, звон кассы, лопнувшая жвачка. Каждый поворот — со звуком-ударом.
- **Свои звуки у каждого сериала.** Claude создаёт набор из 15–25 реалистичных звуков и переиспользует их во всех сериях. Никаких «пищалок» из старых игр.
- **Музыка своя.** Claude синтезирует 8-битный луп кодом — бесплатно. Чужие песни нельзя: YouTube заберёт доход или заблокирует видео.
- **Громкость −14 LUFS** — стандарт площадок. Ролик не будет тише соседних в ленте.

# Как не сжечь кредиты

| Что | Сколько стоит (примерно) |
|---|---|
| Одна реплика | 5–15 кредитов |
| Серия (12–16 реплик + пара новых звуков) | 150–250 |
| Новый звук | 40–200 |
| Голос через Voice Design | 100–200, один раз |
| Минута музыки ElevenLabs | ~900 — поэтому музыку делает код |

:::tip Правила экономии
- Удачные реплики переиспользуются: «Традиция.» кота можно вставить в любую серию бесплатно.
- Новые звуки создаются один раз на сериал и лежат в библиотеке.
- Не проси «перегенерируй все реплики» — только конкретные.
- Распознавание речи (проверка, что сказано) дорогое, Claude его без просьбы не запускает.
:::
