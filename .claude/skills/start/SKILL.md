# /start [slug] — дёшево войти в работу

Цель — не перечитывать 1 700+ строк документов: CLAUDE.md уже загружен, остальное только по нужде.

1. **Прочитать:** `docs/brief.md` (шпаргалка, ~80 строк) и, если задача про сериал, `series/<slug>/STATUS.md` (нет — `README.md` первые 30 строк). Больше ничего целиком не читать.
2. **Git:** `git fetch -q origin main && git log --oneline -3 origin/main`; рабочая ветка = заданная в системном промпте, начинать от `origin/main` (`git checkout -B <ветка> origin/main`), если прошлые PR смёржены.
3. **Окружение одной командой (ключи не печатать):**
   `ffmpeg -version | head -1; python3 -c "import numpy, PIL"; for k in ELEVENLABS_API_KEY XAI_API_KEY; do [ -n "${!k}" ] && echo $k ok; done`
4. **Выбрать скил:**

| Запрос владельца | Скил |
|---|---|
| новый сериал / сезон | `/new-series` |
| серия, пилот, остальные серии | `/episode` |
| замечания к готовой серии | `/fix` |
| файл выкладки | `/publish` |
| длинная 16:9 | `/extended` |
| статистика, таблица, скрины | `/stats` |
| голоса пропали, слоты | `/voices` |
| музыка / лупы | `/music` |
| рендер, сжатие под лимит | `/render` |
| коммит, PR, мердж | `/ship` |

5. **Экономия токенов** (правило владельца 11.10 и 22.10):
   - большие файлы — только `grep -n` / `sed -n a,bp` по разделу;
   - логи — `tail`;
   - картинки — мини-листами 12 планов, полный размер — только кропом;
   - рендер в фоне без опроса;
   - перед концом сессии — обновить `series/<slug>/STATUS.md` (готово / дальше / проблемы / команды).
