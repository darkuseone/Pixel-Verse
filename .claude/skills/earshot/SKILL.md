# /earshot <slug> <epNN> — звук «на слух» (тест владельца с 30.10.2026)

Я не слышу. Про звук говорю только цифрами earshot (LUFS, вердикт critique, % синхрона, доля полос). earshot работает локально на CPU,
аудио никуда не уходит. Полный справочник автора: `upstream_earshot.md` (читать только нужный Loop).

## 0. Установка (раз за сессию, ~3 мин; контейнер эфемерный)
`bash engine/earshot_setup.sh` → `/home/user/tools/earshot/.venv/bin/python -m earshot …` (пин коммита внутри скрипта).
Python earshot = `ES=/home/user/tools/earshot/.venv/bin/python`.

## 1. Лист событий картинки `episodes/epNN/sound/cues.json`
`{fps: 30, total: <кадров>, events: [{f, kind, id, weight}]}` — где ГЛАЗ ждёт звук: каждая склейка (`whoosh`), контакт/удар (`hit`,
`land`), появление стикера/плашки (`pop`), экран-бот (`bell`), поворот (`riser` + `hit` weight 2), падение предмета (`drop`).
Писать из `timeline.py` (CUTS, TWIST) и сценария — до звука, это контракт картинки.

## 2. Послушать микс (≈ 1 мин на шортс)
`$ES engine/earshot_listen.py final.mp4 sound/cues.json build/<bk>/vN > build/<bk>/vN_listen.txt` → читать:
- **critique** (вердикт + FIX FIRST): громкость, присутствие музыки, баланс полос (sub / low / mid / air), стерео, провалы;
- **sync**: % склеек и cues с звуком ±1 кадр и ±100 мс (против «chance»), красные метки = событие без звука;
- **sheet PNG** (`vN_sheet.png`, смотреть уменьшенным) — каша, провалы, поздние удары видны сразу.
Профиль critique — 7 профессиональных launch-фильмов (музыка ведёт). У нас мультфильм с репликами: «mid 1–4 kHz high» от голосов
и «music presence» под речью — это стиль, не ошибка; голос не глушу ради метрики. Всё остальное исправляю.

## 3. Звуки из банка earshot (0 кредитов, без моделей)
`$ES -m earshot sfx list [--kind whoosh|hit|pop|bell|riser|drop]` → батч `[[out, id, {dur, apex, pitch, seed}], …]`
→ `python3 engine/earshot_sfx.py batch.json` (рендер + модельный аудит щелчков/хвостов/клиппинга, перебор seed при варнинге).
Кладу в `series/<slug>/sfx/es/<понятное_имя>.wav` — это звуки сериала, переиспользуются в его следующих сериях.
Что брать (проверено на Land of the Fee E01): склейки — `swish/flick`, `whoosh_fast/whip|tight|sleeve`, большой пролёт —
`whoosh_big/cape` (`--dur --apex`); удары — `cut_hit/punch` + `cut_hit/sub` (саб под удар), `pro_impact/short`; поворот —
`riser/snatch` (пик = удар) + `pro_sub_drop/low --pitch <тоника музыки>`; стикеры — `ui_pop/soft|step|wide`, `pro_pop_in/round`;
бот/экран — `mallet/up4|celesta|glock --pitch`; предметы — `knock/wood`, `drip/bloop`, `shutter/snap`.
Не превращать в «миди-плинки»: поп/чайм ≤ 0,3 громкости, реалистичный фоли (ElevenLabs/свой) остаётся основой.

## 4. Правила микса (timeline.py, `engine/mix.py`)
- Склейка: пик swish/whoosh через +30…40 мс после кадра (старт = t_cut − apex + 0,037); тап/стук на 10–60 мс раньше контакта.
- На раскрытиях саб-слой (sub/kick) — иначе «thin bottom».
- Музыка не обрывается: одна подложка на весь ролик, приглушение под речью 3–6 дБ (`duck` = 0,5–0,6), перед большим ударом
  спад 0,3–0,5 с (`STOP` в фильтре подложки) и возврат на ударе.
- `VOICE_LUFS` — все реплики к одной громкости (иначе тихие дубли и «тихий бот»); эффекты «экрана» без потери гейна
  (`aecho` in_gain 1.0).
- Панорама SFX по месту на экране (6-й элемент −1…1), Haas 9–14 мс на атмосферах и музыке (ширина).
- `MASTER_EQ`: низ (+2…4,5 дБ на 50–90 Гц), −1,5 дБ на 2,4 кГц; итог −14 LUFS / −1 dBTP (`LUFS`).
- Старый микс сохраняю (`sound/timeline_vN.py`), каждую итерацию слушаю заново и сравниваю цифры; меняю по одной группе.

## 5. Отчёт владельцу
Вердикт и цифры до/после (critique, % синхрона, громкость реплик), какие звуки банка добавлены, что осталось «стилем».
Честно: earshot оценивает измерениями и моделями, а не вкусом; финальное слово — уши владельца.
