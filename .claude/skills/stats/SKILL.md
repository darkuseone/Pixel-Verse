# /stats [ru|us]

0. **Читать только:** `docs/brief.md` и в `docs/stats-<рынок>.md` раздел §1 «Главные выводы» плюс последнюю неделю журнала (`grep -n "^### Неделя" docs/stats-ru.md`, затем `sed -n`). Весь файл (300+ строк) не читать.
0. **CSV / таблица владельца:** сначала скопировать в отдельную папку scratchpad, затем `python3 -I engine/statscsv.py <файл>`. Скрипт даёт подписки, комментарии, репосты и сохранения на 1 000 просмотров по роликам и сериалам, выгрузку целиком не читаю. В выгрузке TikTok колонки сдвинуты на одну (учтено в скрипте); строки-дубли одного ролика под разными названиями скрипт отбрасывает. Новый сериал — добавить ключевые слова в `SERIES`. xlsx с личными данными владельца (почта) в git не класть.
1. Рынок по сериалу (РУ → `docs/stats-ru.md`, US → `docs/stats-us.md`), не смешивать.
2. Внести журнал недели (просмотры, охват, «продолжили смотреть», средний %, досмотр, время, лайки, комментарии, репосты, сохранения, подписки) по каждой серии; обновить сводку.
3. Найти секунду просадки (кривая удержания), сравнить серии и хуки, проверить действие плашки подписки (подписки на 1 000 просмотров).
4. Обновить «Главные выводы»; 1–3 конкретные правки для следующих серий → `docs/episode-formula.md` (подтверждённые приёмы / «Чего не делать»).
5. `/ship`; владельцу — 5–7 строк: что работает, что нет, что меняю.
