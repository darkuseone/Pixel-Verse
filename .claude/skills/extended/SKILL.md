# /extended <slug>

По CLAUDE.md §8 шаг 5. Образцы: `series/sunny-palms-hoa/movie/` (каркас kit/shots/blocks/movie.py), `series/florida-man/movie/`.
1. **Сценарий** `series/<slug>/movie/script.md`: самостоятельный мини-фильм с драматургией и столкновениями героев, не шаблон и не «склейка серий в рамке» (CLAUDE.md §8, шаг 5; правило 12.10.2026); структура не повторяет прошлые фильмы; ~30–40 % материала из серий сезона (задники, герои, повороты, куски сцен), новое — только где нужно (дешевле); хук с 0:00, поворот, главы; петля/крючок — по желанию. Отправить, ждать «ок» (если владелец не сказал «делай сразу»).
2. **Ресурсы:** сначала переиспользовать задники/героев/сцены сезона; новые реплики теми же голосами (`voice/movie/lines.json`), 1–3 задника xAI, звуки из библиотеки.
3. **Код:** `PV_WIDE=1`, блоки нового материала на движке v2 (2× герои, декали, антураж), эпизоды — кадры из `episodes/epNN/final_noend` (без плашки подписки!) в новой композиции (экран в сцене, наезды, стоп-кадры).
4. **Контроль:** мини-листы по блокам (машинный критик — для 9:16; для 16:9 смотреть мини-листы глазами), длина, громкость −20…−22 dB.
5. **Плашка подписки** за 3 с до конца (`engine/endcard.py`, ширина 1920).
6. **Сдача:** `final.mp4` ≤ 95 МБ (HEVC при необходимости) → коммит + пуш в main; в чат ТОЛЬКО ссылку на скачивание + файл выкладки (название, описание с главами, хэштеги, воскресное утро). Обложка 1920×1080 jpg ≤ 2 МБ по CTR-правилам `docs/covers.md` §«Обложка длинного видео 16:9» (одно огромное лицо с эмоцией, яркий фон, 1–3 слова, правый нижний угол пуст, проверка `cover_small.png`); каркас `series/florida-man/movie/cover.py`.
