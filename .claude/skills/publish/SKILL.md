# /publish <slug> [сезон]

Читать только `docs/brief.md` §«Выкладка» и образец-файл (первые 40 строк). По CLAUDE.md §8 шаг 4, формат — как `series/florida-man/publish_s01.txt` (US) / `series/mazutych/publish_s01.txt` (РУ).
1. Время по умолчанию (владелец 02.11.2026, Молдова): шорты пн–сб — YouTube 06:55, Instagram 07:05, TikTok 07:15; вс 08:35 — фильм, только YouTube. Сверху — только календарь «серия → дата», без категории, метки «ИИ» и прочих настроек. US — YouTube ≈ 00:30, Instagram ≈ 00:40 по Молдове, TikTok для US не выкладывается (блок не писать). Время не пересчитывать — только если владелец сменил часовой пояс.
2. Поиском время не сверять (слоты заданы владельцем).
3. Блоки YouTube → Instagram → TikTok, серии 1–6; в каждом: название (YouTube ≤ 60 знаков), описание 2–3 предложения с вопросом-выбором, 3–5 хэштегов; тексты разные для каждой сети; без ссылок; стоп-слова рынка.
4. Расширенная версия — воскресенье 08:35, только YouTube, 2–3 таймкода, не больше.
5. В каждом описании — вопрос-выбор (комментарий), в части — призыв переслать; закреп-комментарий.
6. `series/<slug>/publish_sNN.txt` → `/ship` → `SendUserFile`.
