# /publish <slug> [сезон]

Читать только `docs/brief.md` §«Выкладка» и образец-файл (первые 40 строк). По CLAUDE.md §8 шаг 4, формат — как `series/florida-man/publish_s01.txt` (US) / `series/mazutych/publish_s01.txt` (РУ).
1. Время один раз сверху, по Молдове, без округления; РУ — каждый день утром (TikTok ≈ 07:30–08:15 МСК, YouTube −15 мин, Instagram +15 мин; с 25.10 по Молдове на час раньше); US — американский вечер в молдавском времени, предупредить о рассинхроне часов (25.10–01.11, 14–28.03).
2. Сверить оптимальное время поиском (WebSearch standard), не спорить по вечерам с другими сериалами канала (`docs/series-list.md`).
3. Блоки YouTube → TikTok → Instagram, серии 1–6; в каждом: название (YouTube ≤ 60 знаков), описание 2–3 предложения с вопросом-выбором, 3–5 хэштегов; тексты разные для каждой сети; без ссылок; стоп-слова рынка.
4. Расширенная версия — воскресное утро, главы с таймкодами.
5. В каждом описании — вопрос-выбор (комментарий), в части — призыв переслать; закреп-комментарий.
6. `series/<slug>/publish_sNN.txt` → `/ship` → `SendUserFile`.
