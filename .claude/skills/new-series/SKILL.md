# /new-series <ru|us> [тема] — сериал или сезон до «ок» владельца

Правила — CLAUDE.md (§1–§5, §8 шаги 1–2) и `docs/episode-formula.md`; здесь только порядок, ничего не пропускать.

1. **Рынок.** Если не назван — один вопрос: РУ или США. Рынки не смешивать.
2. **Чтение (grep/sed, не целиком без нужды):** `docs/stats-<рынок>.md` (главные выводы + последние недели) → `docs/humor-<рынок>.md` (банк, «Уже использовано», пародийные бренды) → `docs/series-list.md` → `docs/covers.md` → `docs/voices.md`. Для сезона 2: `series/<slug>/STATUS.md`, `README.md`, `voices.json`, крючок прошлого финала.
3. **Разведка:** WebSearch по актуальной боли рынка и мемам недели (standard, несколько запросов разом). Дописать раздел с датой в `docs/humor-<рынок>.md` (таблица мем → смысл → как вкладываем → статус).
4. **Герои (только новый сериал):** skill `anthropic-skills:canvas-design` → `series/<slug>/design/philosophy.md` + `cast_sheet.png`; сверить с героями других сериалов (силуэт, риг, палитра не повторяются); `design:design-critique`. Свой риг-модуль `engine/props/<kit>pix.py` / `<kit>cast.py` на основе `dibspix` (2× разрешение, `txt_box`), свой `<kit>decor.py` под антураж.
5. **Сценарий сезона** одним txt `series/<slug>/season<N>_script.txt` по формуле: на каждую из 6 серий хук (кадр + текст-хук + реплика), биты с таймкодами, поворот 50–60 % и ≤ 18 с (тип не повторяется), кнопка, петля, коллбэки, визуальные шутки и местные надписи; 30–32 с; обложка (сетка профиля); голоса; задники. Плюс «чем бьёт по метрикам».
6. **Отправить** файл `SendUserFile` + 3–4 строки сути. Записать заказ в `docs/decisions.md`, создать `series/<slug>/STATUS.md`. Коммит + пуш.
7. **Стоп:** до «ок» голоса, звуки и задники не генерировать (кроме «делай сам»). После «ок» → `/episode <slug> 1`.
